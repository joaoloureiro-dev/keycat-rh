## About

Keyboard Cat is an iconic internet meme featuring a cat named Fatso, whose keyboard performance became one of the internet’s most recognizable early memes.

The legacy continued with Bento and Skinny, carrying Keyboard Cat forward across different eras of internet culture.

## Live Market Data

Market information is retrieved from the DEX Screener API.

The website can display:

- Price
- 24H price change
- Market capitalization
- Liquidity
- 24H volume

Market data automatically refreshes periodically.

If the token has not yet been indexed by DEX Screener, unavailable values use appropriate fallback states instead of displaying fake market information.
